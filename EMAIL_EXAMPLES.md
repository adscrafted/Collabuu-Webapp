## Visual Design Elements

### Color Scheme

All emails use consistent branding colors:

- **Header Background:** Indigo (#6366f1)
- **Header Text:** White (#ffffff)
- **Primary Text:** Dark Gray (#374151)
- **Secondary Text:** Medium Gray (#6b7280)
- **Links:** Indigo (#6366f1)

### Status Badges

**Approved Status:**
- Background: Light Blue (#dbeafe)
- Text: Dark Blue (#1e40af)
- Label: "Approved"

**Completed Status:**
- Background: Light Green (#d1fae5)
- Text: Dark Green (#065f46)
- Label: "Completed"

**Rejected Status:**
- Background: Light Red (#fee2e2)
- Text: Dark Red (#991b1b)
- Label: "Declined"

### Information Boxes

**Standard Info (Gray):**
- Background: #f9fafb
- Border: #e5e7eb
- Used for: Withdrawal details table

**Success Info (Green):**
- Background: #d1fae5
- Border: #10b981
- Used for: Success messages, completion confirmation

**Info Notice (Blue):**
- Background: #eff6ff
- Border: #bfdbfe
- Used for: Credits restored, keep for records

**Warning/Error (Red):**
- Background: #fef2f2
- Border: #fecaca
- Used for: Rejection reason

**Help Box (Light Green):**
- Background: #f0fdf4
- Border: #bbf7d0
- Used for: Support assistance options

## Mobile Responsiveness

All templates are fully responsive and will display correctly on:

- Desktop email clients (Outlook, Apple Mail, Thunderbird)
- Web email clients (Gmail, Yahoo, Outlook.com)
- Mobile devices (iOS Mail, Gmail app, Outlook app)
- Tablets (iPad, Android tablets)

### Mobile Optimizations

- Single column layout (no complex grids)
- Touch-friendly button sizes
- Readable font sizes (16px minimum)
- Optimized image sizes
- Collapsible sections where appropriate

## Accessibility Features

All templates include:

- **Semantic HTML:** Proper heading hierarchy
- **Alt text:** For all images (if added in future)
- **Color contrast:** WCAG AA compliant
- **Screen reader friendly:** Proper table structure
- **Plain text fallback:** All emails have text version

## Email Client Compatibility

Tested and working in:

- ✅ Gmail (web, iOS, Android)
- ✅ Apple Mail (macOS, iOS)
- ✅ Outlook (web, Windows, macOS)
- ✅ Yahoo Mail
- ✅ ProtonMail
- ✅ Thunderbird
- ✅ Samsung Email
- ✅ Spark

### Known Issues

- Some older Outlook versions may not render rounded corners
- Dark mode appearance may vary by email client
- Custom fonts fallback to system fonts in some clients

## Customization Examples

### Change Brand Color

Edit `/lib/email/templates/layout.tsx`:

```typescript
const header = {
  padding: '32px 48px',
  backgroundColor: '#YOUR_COLOR_HERE', // Change this
  textAlign: 'center' as const,
};
```

### Add Company Logo

Edit `/lib/email/templates/layout.tsx`:

```typescript
<Section style={header}>
  <Img
    src="https://yourdomain.com/logo.png"
    alt="Collabuu"
    width="150"
    height="50"
  />
</Section>
```

### Update Footer Text

Edit `/lib/email/templates/layout.tsx`:

```typescript
<Text style={footerText}>
  Your custom footer text here
</Text>
```
